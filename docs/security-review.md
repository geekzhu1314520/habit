# 五轴审查与安全加固

审查日期：2026-10-01。范围：当前跑步专用应用、全部源代码、测试、存储接口与构建配置。没有通用习惯名称字段，不新增名称编辑或 streak 功能。

## 结论与发现

| 级别 | 发现 | 处理 |
|---|---|---|
| Required / P2 | localStorage 文档和记录缺少规模限制，允许任意附加字段；结构合法的大量数据可拖慢同步加载 | 已修复：解析前限制 2,000,000 个 UTF-16 字符；最多 10,000 次记录、id 最长 128 字符；精确字段白名单与普通对象检查。超限或异常保留原值并报 INVALID_DATA |
| Required / P2 | 历史列表对每个日期重新扫描全部记录，复杂度 O(天数 × 记录数) | 已修复：一次按日期分组；漏跑查找使用 Set；总体约 O(n + d log d) |
| Defense in depth | 字符串模板依赖上游日期校验，未来修改可能引入 HTML 插值问题 | 已补显式 HTML 文本/引号属性转义；错误提示仍使用 textContent。当前未确认存在可利用的名称 XSS |
| Required / P2 | 应用服务没有 CSP 等基础响应头，依赖安装未固定脚本策略 | 已为开发与构建预览添加响应头，固定 npm 11.5.1，并以 ignore-scripts=true 禁止依赖生命周期脚本；干净安装后完整验证通过 |

未发现剩余的已确认 Critical 问题。以下结论限于当前本地应用，并不等于全面安全认证。

## 五个维度

1. **正确性**：隔天日程、未完成的今天、漏跑、同日累计、刷新、编辑删除与冲突测试通过。损坏、错误类型、未知版本、重复 id、日期越界、数值溢出均在存储边界拒绝。新增严格字段检查会拒绝旧代码曾忽略的额外字段，不静默丢弃它们。
2. **可读性与简洁性**：字段形状检查与输出编码分别由小型助手函数负责；未增加通用安全框架或依赖。UI 协调文件仍承担多个流程，属于可选维护改进；当前不为审查而重写整套 UI。
3. **架构**：load/save 使用统一 result 契约，校验在存储入口，领域计算接收已校验数据；界面不直接读写 localStorage。输出编码在渲染层。模块依赖保持单向。
4. **安全性**：真实浏览器测试篡改 name/date/id 中的 img、svg、事件处理器，确认无攻击元素、弹窗或攻击域名请求；异常原文保留。不存在账号、令牌、数据库查询、文件上传、服务端 URL 抓取、LLM 或外部数据服务，因此相应认证、SQL、SSRF 等检查不适用。
5. **性能**：修复按日重复扫描；数据规模设有确定上限。10,000 条历史仍可能产生较多 DOM，未来若正常使用接近上限，可增加分页；本次不承诺低端设备上限场景的性能指标。

## 威胁模型

资产：本机跑步历史、累计与日程正确性、页面执行环境、用户输入草稿。

| 边界 | STRIDE 风险 | 控制与限制 |
|---|---|---|
| 表单 → 应用 | 篡改/拒绝服务 | 日期、距离、精度、范围校验；没有自由文本名称输入 |
| localStorage → 应用 | 篡改/披露/拒绝服务 | 原文长度、字段形状、类型、日期、唯一性、总和及数量校验；错误不输出原文；不自动修复或清空 |
| 数据 → DOM | 脚本注入引发披露/权限滥用 | 文本转义、textContent、经过校验的数值插值、CSP；id 从不插入 HTML |
| 多标签页 → 存储 | 覆盖/否认 | 快照冲突检测和草稿保留；不声称 localStorage 有原子事务或审计认证 |
| 依赖 → 构建 | 供应链执行 | 精确版本与锁文件、禁用安装脚本、官方 npm 已知漏洞审计 |

能够写 localStorage 的同源脚本仍能伪造一份**格式合法**的跑步历史；客户端校验不能认证真实运动记录，也不能抵御已控制浏览器的攻击者。此应用没有权限或身份认证用途，不把这些数据当作授权依据。

## 名称 XSS 的实际覆盖

产品名称“跑步”为固定文案。注入额外 name 字段会因 schema 白名单失败而被拒绝，不能进入渲染。另测试了包含 HTML 的字符串经 escapeHtml 后仅显示原文，不生成元素。未来若新增名称，应将字段纳入 schema 并用 textContent 渲染，不能直接插入 innerHTML；不能把本次测试当作尚不存在功能的验证。

## 部署与供应链剩余边界

开发服务为 Vite 热更新允许内联样式；构建预览使用严格 style-src 'self'，两者均不允许内联脚本。Vite 配置不会自动成为任意静态托管平台的响应头；正式发布前需在实际 HTTPS 托管配置同等 CSP/响应头及 HSTS。本轮未部署生产服务，也未添加虚假的 localhost HSTS 保证。

已知漏洞审计不能证明包的来源可信，本轮未验证注册表签名/出处证明。没有 CI 系统，未声称 CI 已执行安全门禁；项目级 .npmrc 为后续 npm 安装禁用生命周期脚本。正式发布前应执行官方审计并验证来源与部署响应头。
